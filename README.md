# CodeAlpha - Language Translation Tool

## Description

This project is a Language Translation Tool developed using Python and the Google Translate API. The application allows users to enter text, select source and target languages, and receive instant translations. It demonstrates the use of Natural Language Processing (NLP) and translation APIs for multilingual communication.

## Features

* Translate text between multiple languages
* User-friendly text input
* Source and target language selection
* Instant translation output
* Optional text-to-speech support
* Easy to use and interactive

## Technologies Used

* Python
* Googletrans Library
* Google Colab
* NLP Concepts

## How It Works

1. User enters the text to be translated.
2. User selects the source language.
3. User selects the target language.
4. The text is sent to the translation API.
5. The translated text is displayed to the user.
